# Guide

## Installation

Install Python 3.11 or newer, create a virtual environment and run `pip install -r requirements.txt`.

## Quick start

Index a folder of notes, then ask a question. The first run takes a minute while the index is built.

## Searching these docs

Use the search box at the top of the docs site to find a page. Results are ranked by title match first, then body text.

## Writing good queries

Short, specific questions work best. Mention the product area and what you were trying to do.

## Ranking and relevance

Results are ordered by similarity score. Ties are broken by recency, newest first.

## Result pagination

Large result sets are split into pages. Use the next page link at the bottom of the results list.

## Supported file types

Plain text, markdown and PDF files can be indexed. Images are skipped.

## Language support

English and Japanese are supported. Other languages may work but are not tested.
