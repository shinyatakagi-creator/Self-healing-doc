# Notes

## Searching notes

To find a note, send the text you are looking for to the search endpoint. By default the search returns at most ten results, best match first.

## Sharing notes

Share a note by sending a link. Anyone with the link can read it, and you can turn the link off at any time.

## Exporting notes

Export a notebook as markdown or PDF from the menu. Attachments are included in the export.

## Keyboard shortcuts

Press the question mark key to see all shortcuts. Most actions have a single-key shortcut.
